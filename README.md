# Project Hub

One-page index of the tools, dashboards and sites Jon has built. Each linked site handles its own authentication; this page holds links only.

Hosted on GitHub Pages: https://jon-oh-io.github.io/project-hub/

## Adding a project

Add an entry to the `PROJECTS` array in `index.html` (group, name, desc, url, org, access, repo), bump `UPDATED`, and push to `main`.
